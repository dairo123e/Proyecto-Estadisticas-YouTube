# Proyecto estadísticas de YouTube: Avance II

Esta carpeta contiene la segunda etapa del proyecto, enfocada en el análisis estadístico, selección de variables, comparación de modelos y selección inicial de Gradient Boosting.

## Resultados principales

Se compararon cinco modelos:

- Modelo base.
- Regresión logística.
- Árbol de decisión.
- Random Forest.
- Gradient Boosting.

Gradient Boosting obtuvo:

- Accuracy: 0.9409
- Precision: 0.9505
- Recall: 0.9301
- F1-score: 0.9402
- ROC-AUC: 0.9880
